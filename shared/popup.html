Playnite connection setupStandard or portable

Select your Playnite database with the Windows file chooser. The 5 MB JSON / CSV limit does not apply.

For portable Playnite, enter the full path to games.db. Keep sources.db in the same folder. The local native bridge is required.

Where is my Playnite library?

Standard installations usually use:

%APPDATA%\Playnite\library\games.db

Portable installs keep the library in their own folder. Direct mode reads protected copies and never modifies either database. If Playnite locks them, close it or use the optional SDK exporter. Follow the project's README to install the local bridge.

      Connection & privacy details

      Microsoft's documented Store entitlement APIs support publisher catalogs, not a general personal library connection for this extension. No Microsoft password, cookie, client secret, or access token is collected here. Authenticate only through Microsoft-hosted sign-in in the Playnite integration you choose. Update your library in Playnite first. For updates while Playnite is running, use the optional SDK exporter; direct games.db access requires Playnite to release its locks.

      Your choice, clearly marked.

      Blue YOU OWN THIS means purchased; green means Game Pass access. Violet WANT TO OWN is a purchase-interest choice, like a wishlist entry. Red "Done" means done playing and not buying; it does not mean purchased.

      Microsoft purchase verification (optional)

      Open Microsoft order history yourself. Confirm Completed or Redeemed GAME purchases (not Game Pass, add-ons, refunds or trials). Highlight only the GAME TITLES on that page. The extension only reads text you deliberately select after pressing Capture. No invoices, payments, cookies or passwords are collected.

      Nothing is checked until you choose Capture or enter titles manually.

      Review and remove records at any time. Verification is user-confirmed, not an official Microsoft entitlement API. A later Playnite refresh will not erase your verified records. Matching is by exact normalized title and may confuse editions.
