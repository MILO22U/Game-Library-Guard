For portable Playnite, enter the full path to games.db. Keep sources.db in the same folder. The local native bridge is required.

Where is my Playnite library?

Standard installations usually use:

%APPDATA%\Playnite\library\games.db

Portable installs keep the library in their own folder. Direct mode reads protected copies and never modifies either database. If Playnite locks them, close it or use the optional SDK exporter. Follow the project's README to install the local bridge.
